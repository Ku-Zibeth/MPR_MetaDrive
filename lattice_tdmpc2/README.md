# Lattice + TD-MPC2 + Residual SAC

This workflow is independent from the Flow Matching workflow and does not require
a Flow checkpoint. The recommended order is to prepare a TD-MPC2 world model,
choose frozen or online world-model updates, train the two-dimensional
`[delta_d, delta_v]` residual SAC policy, and then evaluate it on random scenes.

The old discrete residual grid search and 16-candidate trajectory guidance have
been removed. SAC directly emits one residual, Lattice regenerates one refined
trajectory, and TD-MPC2 only scores the nominal and refined trajectories:

```text
planner.type=lattice_tdmpc_sac
residual_rl.training_mode=sac_residual_frozen_wm
```

The residual uses zero-centered linear mappings, `delta_d=u_d*delta_d_max` and
`delta_v=u_v*V0`, so the refined target-speed range is `[0,2*V0]`. Residual SAC
uses the projected dual-gradient update `lambda=max(0, lambda + lagrangian_lr *
(episode_cost-cost_limit))`. Only the environment safety cost trains the twin
cost critics and updates lambda. Invalid refined paths fall back to the nominal
path and remain diagnostic-only; they do not add an artificial constraint cost.
Vehicle collisions remain non-terminal.

Environment safety cost is the dense risk-field cost plus a deduplicated one-shot
event cost. Aliases such as `cost`, `crash`, and `crash_vehicle` are merged, and
a persistent contact is charged only on its first step. Cost-critic bootstrapping
and the actor safety term use the twin-critic mean; the cost critics use Huber
loss to reduce conservative overestimation from long-tailed events. Old SAC
checkpoints with a different action mapping are incompatible, while existing
TD-MPC2 checkpoints remain reusable.

This directory implements a closed-loop residual trajectory planner:

```text
MetaDrive geometry -> Lattice nominal path tau0 ---------------------+
MetaDrive observation -> TD-MPC2 encoder + scorer -> z,J0,C0 --------+--> residual SAC
                                                                     |      [u_d,u_v]
                                                                     v
                               Lattice regenerate(d0+delta_d,V0+delta_v,T0)
                                                -> hard safety filter
                                                -> TD-MPC2 score refined path
                                                -> existing path tracker
                                                -> real MetaDrive transition
```

Lattice and the TD-MPC2 encoder are parallel branches. Lattice never receives
the latent state. Lattice selects one nominal path using its original handcrafted
selector; SAC emits one residual and Lattice regenerates one refined path.
TD-MPC2 only predicts scores for the nominal and refined paths. It does not
generate trajectories or sample residual candidates.

## Confirmed Interfaces

- TD-MPC2 and MetaDrive use normalized `[steering, throttle_brake]`.
- Residual SAC uses exactly two normalized actions `[u_d,u_v]`.
- `LatticeActionAdapter` converts a path into `[N,H,2]` low-level action
  sequences using virtual future tracking states; it does not repeat the first
  real-vehicle action.
- Replay stores normalized residual actions. Physical `delta_d` and `delta_v`
  are logged.
- Existing TD-MPC2 checkpoints without trained `_cost` weights must use
  `residual_rl.use_world_model_cost=false`.

## Residual State And Action

The fixed path feature vector contains 12 normalized values:

```text
target_d, target_speed, horizon, min_obstacle_clearance, obstacle_cost,
max_abs_d_d, max_abs_d_dd, max_abs_d_ddd, max_abs_s_dd, max_abs_s_ddd,
curvature_max, path_length
```

`lattice_sac` uses only these features. TD-MPC2 modes use
`[z_t, path_features, J0]` by default; `C0` and `U0` are independently
configurable. The dimension is inferred from the first real state.

Both normalized residual actions use zero-centered linear mappings. With lateral
width `W=delta_d_max` and coarse target speed `V0`:

```text
delta_d = u_d * W       u_d in [-1,1] -> delta_d in [-W,+W]
delta_v = u_v * V0      u_v in [-1,1] -> delta_v in [-V0,+V0]
```

Therefore `u_v=-1` requests a refined target speed of zero, `u_v=0` keeps the
coarse target speed, and `u_v=+1` requests twice the coarse target speed:

```text
d_ref = d0 + delta_d
V_ref = V0 + delta_v
T_ref = T0
```

Every refined path is regenerated by the existing Frenet polynomials and is
checked again for finite geometry, road bounds and collision. Any regeneration,
safety, or world-model failure executes `tau0`, records `unsafe_residual` when
appropriate, and sets the physical residual to zero.

## Learning

The critic and actor use standard SAC learning based on the real MetaDrive reward:

```text
y = r_env + gamma * (min(Q1_target,Q2_target) - alpha*log_pi)
```

Residual training enables a projected Lagrangian multiplier by default. Twin cost critics learn only
from the environment safety cost:

```text
y_cost = c + gamma * mean(QC1_target, QC2_target)
L_actor = (L_SAC + lambda * mean(QC1,QC2)) / (1 + lambda)
```

The environment cost is a dense normalized risk-field cost plus one deduplicated
event cost. Generic and specific flags for the same crash are merged, and a
continuous contact is charged as an event only on its first step. Cost critics
use Huber loss to reduce sensitivity to the remaining long-tailed targets.

The multiplier is updated after each completed episode with
`lambda <- max(0, lambda + lagrangian_lr * (episode_cost - cost_limit))`.
`residual_rl.cost_limit` defaults to `10` and `residual_rl.lagrangian_lr`
defaults to `0.01`; the recommended V3 experiment explicitly overrides
`cost_limit=5`. Vehicle/object collisions remain
non-terminal, but their cost is retained and propagated by the cost critics.
Unsafe residual paths still fall back to the nominal Lattice path and are logged
as `residual/unsafe`, but they do not add an artificial constraint cost.

For every decision, TD-MPC2 scores the single nominal Lattice path and the single
SAC-refined path. These predictions provide latent/score state features and
diagnostic metrics; they do not create an actor imitation loss or replace the
real MetaDrive reward. In online-WM mode, TD-MPC2 continues learning from the
executed low-level transition independently of the SAC gradient.

```text
delta_d = u_d * current_lane_width

c_wm = sum(t=0..9, 0.99^t * c_t) + 0.99^10 * terminal_cost_Q
L_cost_critic_v4 = Huber(QC1,c_wm) + Huber(QC2,c_wm)
```

叠加下一状态 target cost critic。真实 MetaDrive cost 仍用于日志和评估，不写入
V4 replay 的约束标签。lambda 每个 episode 使用 `c_wm` 的逐决策均值更新，避免
把相互重叠的 cost-to-go 再按 episode 长度求和。

### 共同实验配置

三个版本均使用 `seed=1` 训练 1,000,000 个环境步，训练场景为 `[100,150)`
共50个 MetaDrive seed。主要共同配置如下：

| 项目 | 配置 |
| --- | --- |
| observation | 259维 MetaDrive state，经 TD-MPC2 encoder 得到512维 latent |
| residual state | 512维 latent + 12维 Lattice 特征 + `J0,C0`，合计526维 |
| SAC action | 2维 `[u_d,u_v]`，网络输出范围 `[-1,1]` |
| SAC network | actor、双 reward critic，V2/V3 另有双 cost critic；MLP `[256,256]` |
| replay | 200,000，batch 256，`n_step=1`，`gamma=0.99` |
| update | 前5,000步随机动作；5,000步后训练；每环境步累计0.2次 SAC update |
| optimizer | actor lr `5e-4`，critic lr `1e-3`，alpha lr `3e-4` |
| entropy | `alpha=0.005` 初始化，`auto_alpha=true` |
| target update | Polyak `tau=0.05` |
| Lattice | 目标速度13.89 m/s，候选时域2/3 s，速度偏移0/-4/-8 m/s |
| TD-MPC2 score horizon | 3步；reward 末端有 Q，cost 仍没有 terminal cost-Q |
| MetaDrive | `traffic_density=0.1`，`accident_prob=0.8`，episode horizon 1000 |
| termination | 撞车不终止，驶出道路终止 |
| checkpoint/eval | 每50,000步保存和评估，评估10个 episode |

三个版本始终用真实 MetaDrive reward 训练 reward critic：

```text
y_r = r + gamma * (1-done) * (min(Q1_target,Q2_target) - alpha*log_pi)
L_reward_critic = MSE(Q1,y_r) + MSE(Q2,y_r)
L_SAC = mean(alpha*log_pi - min(Q1,Q2))
```

TD-MPC2 的预测 reward/cost 是 SAC state 和诊断信息；只有 V1 曾额外把 world
model 评价写入 actor auxiliary loss。V2/V3 均不让 TD-MPC2 生成或筛选多条
残差轨迹。

### V1：16候选 + 在线世界模型 + SAC

| 项目 | 内容 |
| --- | --- |
| W&B run | `lattice_tdmpc_sac_online_wm_cost_seed1`，run id `kafnd4rl`，2026-09-08 |
| planner | `lattice_tdmpc_sac_wm_guided` |
| SAC checkpoint | `logs/residual_sac/lattice_tdmpc_sac_online_wm_cost_seed1/final.pt` |
| 配套世界模型 | 同目录 `world_model_final.pt` |
| 初始世界模型 | `logs/metadrive-risk/1/tdmpc2_mppi_teacher_cost_v2/models/final.pt` |
| 世界模型更新 | 在线更新，`online_wm_update_every=1` |
| 动作映射 | 旧映射：动态横向边界；`delta_v_max=2.0m/s`；无版本标记 |
| 安全约束 | 无 Lagrangian、无 cost critic；环境 cost 只记录并训练 WM cost head |

V1 让 SAC 采样16个 residual candidate，再由 TD-MPC2 world model 评价，并把
world-model auxiliary loss 和 trust loss 加入 actor：

```text
L_actor_v1 = L_SAC + 0.1 * L_wm_aux + 0.01 * L_trust
```

`L_wm_aux` 鼓励 actor 产生被世界模型评为高 return、低 cost 的候选；
`L_trust` 压制远离 Lattice 粗轨迹的大残差。W&B 最后一组数值也满足该组合：
`-17.7608 + 0.1*(-1.5053) + 0.01*(1.2829) = -17.8985`，与记录的
`loss/actor=-17.8985` 一致。

V1 的主要问题：

- 16候选机制改变了“让 SAC 直接学习单个 residual”的目标，额外增加 WM 偏差。
- 速度残差只有 `[-2,+2]m/s`，不能从13.89 m/s直接修正到完全停车。
- 在线更新 encoder，但 SAC replay 保存历史 latent，输入分布持续漂移。
- trust loss 会惩罚必要的大幅刹车和横向避障。
- 没有 SACL，真实安全 cost 不直接约束 actor。
- 当前代码要求 `symmetric_coarse_speed_v2`，因此会拒绝直接加载 V1 SAC；其
  `world_model_final.pt` 仍可作为普通 TD-MPC2 checkpoint 使用。

W&B 末次评估：`R=303.64, C=3.89, success=0.70`；V1 的 `best.pt` 对应
1,000,000步。

### V2：直接 residual + 在线世界模型 + PID-SACL

| 项目 | 内容 |
| --- | --- |
| W&B run | `lattice_tdmpc_sacl_online_wm_v2_seed1`，run id `1hbs0hck`，2026-09-10 |
| planner | `lattice_tdmpc_sac` |
| SAC checkpoint | `logs/residual_sac/lattice_tdmpc_sacl_online_wm_v2_seed1/final.pt` |
| 配套世界模型 | 同目录 `world_model_final.pt` |
| 初始世界模型 | V1 的 `world_model_final.pt`，不是原始教师 |
| 世界模型更新 | 继续在线更新，`online_wm_update_every=1` |
| 动作映射 | `symmetric_coarse_speed_v2` |
| Lagrangian | PID `[Kp,Ki,Kd]=[0.05,0.0005,0.1]`，`cost_limit=10` |

V2 删除16候选和 `L_wm_aux`，SAC 每步直接输出唯一 `[u_d,u_v]`：

```text
delta_d = u_d * 0.4
delta_v = u_v * V0
V_ref = V0 + delta_v, theoretical range [0,2*V0]
```

但 V2 的 tracker 当 `target_speed=0` 时又恢复成13.89 m/s，因此“理论完全停车”
没有正确执行。V2 新增双 cost critic 和 PID Lagrangian。当时约束 cost 还包含
人为 fallback cost：

```text
c_constraint = c_env + 1.0 * I(unsafe_residual)
y_cost_v2 = c_constraint + gamma * max(QC1_target,QC2_target)
L_cost_critic_v2 = MSE(QC1,y_cost_v2) + MSE(QC2,y_cost_v2)

L_actor_v2 = (L_SAC + lambda * max(QC1,QC2)) / (1+lambda)
             + 0.01 * L_trust
```

其中 lambda 按变长 episode 用 PID 更新，并保留积分/微分历史。日志中的
`C_lag` 就是 `C + unsafe_residual` 次数，例如 `C=15.63, C_lag=22.63`。

V2 的主要问题：

- encoder 仍在线变化，而 replay 中的旧 latent 不会重编码，SAC 输入非平稳。
- `unsafe_residual` 一度占约束 cost 的主要部分，使优化目标偏离真实碰撞/风险。
- PID 积分残留且按长度不同的 episode 更新，lambda 明显振荡。
- cost target 用 twin critic 最大值且使用 MSE，容易保守高估和受长尾冲击。
- 同一碰撞的通用/具体标志以及连续接触存在重复计数。
- trust loss 仍压制大幅制动，零目标速度又被执行层恢复。
- WM cost 只前看3步且没有 terminal cost-Q，W&B 后期预测值接近零，安全信息弱。

W&B 末次评估：`R=302.12, C=6.02, success=0.70`。按 eval return 保存的
`best.pt` 在850,000步：`R=321.94, C=4.30, success=0.80`。

V2 checkpoint 可用于当前可视化和 warm start。只有显式设置
`algorithm_version=lattice_tdmpc2_v2`，或用 `--config-name
versions/v2/config_v2` 启动时，才会恢复 V2 的 PID、trust、unsafe cost、旧事件
cost 与零速回退语义。checkpoint 不含 replay buffer 和环境 RNG，因此即使使用
V2 源码也只能从相同网络状态 warm start，不能逐步复现中断点。

### V3：冻结世界模型 + 修正后的 SACL

| 项目 | 内容 |
| --- | --- |
| W&B run | `lattice_tdmpc_sacl_frozen_wm_cost5_v3_seed1`，run id `qkzu62g9`，2026-09-11 |
| planner | `lattice_tdmpc_sac` |
| SAC checkpoint | `logs/residual_sac/lattice_tdmpc_sacl_frozen_wm_cost5_v3_seed1/final.pt` |
| 最佳 checkpoint | 同目录 `best.pt`，对应300,000步 |
| 世界模型 | 原始 `tdmpc2_mppi_teacher_cost_v2/models/final.pt` |
| 世界模型更新 | 完全冻结；V3 目录不重复保存 world model |
| 动作映射 | `symmetric_coarse_speed_v2`，并修复零目标速度执行 |
| Lagrangian | 投影对偶梯度，`cost_limit=5`，`lagrangian_lr=0.01` |

V3 针对 V2 的不收敛因素做了以下调整：

1. 冻结 TD-MPC2 encoder/world model，消除 replay latent 非平稳。
2. 删除 PID，episode 结束后仅做投影对偶梯度更新：

```text
lambda <- max(0, lambda + 0.01 * (episode_cost - 5.0))
```

3. 删除 `L_trust`，actor 只保留 SAC 与 Lagrangian safety 两项。
4. `unsafe_residual` 只触发回退和日志，不再加入训练 cost。
5. 允许 `target_speed=0` 传入 tracker，真正执行完全停车。
6. 环境 cost 改成“逐步风险场 + 去重后的单次事件”：同类碰撞别名取最大值，
   持续接触只在首次 step 计事件 cost。
7. cost target 从双 critic 最大值改为均值，cost critic 从 MSE 改为 Huber。

当前 V3 loss 为：

```text
c = c_risk_each_step + c_new_event_once
y_cost_v3 = c + gamma * (1-done) * mean(QC1_target,QC2_target)
L_cost_critic_v3 = Huber(QC1,y_cost_v3) + Huber(QC2,y_cost_v3)

L_safety = lambda * mean(QC1(s,pi(s)),QC2(s,pi(s)))
L_actor_v3 = (L_SAC + L_safety) / (1+lambda)
```

W&B 末次评估：`R=279.60, C=2.21, success=0.50`。按 eval return 保存的
`best.pt` 在300,000步：`R=296.03, C=1.90, success=0.70`。

### 版本对比结论

| 变化 | V1 | V2 | V3 |
| --- | --- | --- | --- |
| residual 决策 | 16候选 + WM auxiliary | SAC 单输出 | SAC 单输出 |
| 速度映射 | 固定 `+/-2m/s` | `+/-V0`，但零速执行有 bug | `+/-V0`，零速已修复 |
| world model | 在线，从原始教师开始 | 在线，从 V1 final 开始 | 原始教师冻结 |
| safety actor loss | 无 | PID-Lagrangian | 投影对偶 Lagrangian |
| `cost_limit` | 不适用 | 10 | 5 |
| trust loss | 0.01 | 0.01 | 删除 |
| unsafe fallback cost | 不约束 actor | `+1/step` 加入约束 | 删除，仅诊断 |
| cost bootstrap | 无 cost critic | twin max | twin mean |
| cost critic loss | 无 | MSE | Huber |
| event cost | 旧逐步/重复语义 | 旧逐步/重复语义 | 别名去重 + 持续事件单次计数 |
| 当前用途 | 仅保留历史和 WM | 可视化/历史对照 | 当前推荐基线 |

注意：三个 run 每50,000步只评估10个 episode，方差较大；而且 V3 修改了
cost 统计语义，所以 V1/V2/V3 的 `eval/cost` 不能视为完全同口径结果。正式
比较应使用同一版当前环境、同一批固定测试 seed，分别加载三个策略重测。

### 尚未解决的共同限制

- 这三个历史版本使用的 TD-MPC2 trajectory score 均只展开3步。
- 三版配套世界模型的 reward 使用 terminal Q，但 cost 没有 terminal cost-Q；
  后来新增的10步 cost-Q 世界模型不属于 V1/V2/V3 这三次已完成实验。
- V3 冻结解决了 latent 漂移，但不会修正原世界模型在新策略分布上的预测误差。
- `best.pt` 当前按 eval return 而不是“满足 cost limit 后的 return”保存。

## Ablations

| `planner.type` | Residual state | TD-MPC2 scoring |
|---|---|---|
| `lattice` | none | no |
| `lattice_sac` | path features | no |
| `lattice_tdmpc_sac` | latent + path + coarse WM values | yes |

`residual_rl.training_mode=sac_residual_frozen_wm` is the recommended default.

The required overrides relative to the V3 command above are:

`residual_rl.freeze_tdmpc2=true`; only the V3 SAC actor, reward critics, cost
